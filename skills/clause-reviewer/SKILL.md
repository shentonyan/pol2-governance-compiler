# 条款审查者（草稿 v0.1）

任务：核对编译产物是否覆盖了宿主需求声明的每一条条款，以及它的处置是否与契约一致。

## 检查项

1. 宿主声明的每条条款都有对应的判定问题和 status → action 映射。
2. 契约中的非触发项（正当批评、正当愤怒、拒绝、异议、求救）不会被映射为 block。
3. 本体的硬规则没有被违反，例如"温柔措辞不构成免责""值守安全的恨不判违规"。
4. 配置中的每个阈值都附有来源 case id 清单。

## 产出

一份逐条款的审查表：条款 id、覆盖与否、发现、建议。审查表只引用契约和本体原文，不加入审查者自己的解读。

## 规则

- 不看评测分数，以免按分数倒推审查结论。
- 遇到契约没写清的情形，写进 `rulings/OPEN.md`，审查表里标"待裁定"。
