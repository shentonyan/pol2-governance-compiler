# 裁定队列

编译、审查或评测中遇到的条款歧义，不由 Agent 自行补规则，而是记入 [OPEN.md](OPEN.md)，等 NaturalDAO 团队裁定（对应 PoL 项目的 ★ 流程）。

流程：

1. 发现歧义 → 在 OPEN.md 加一行：编号、来源、问题、相关条款、影响哪些契约或场景族。
2. 团队裁定 → 按 [TEMPLATE.md](TEMPLATE.md) 新建 `R-<编号>-<短名>.md`，写明候选解读、决定、理由、裁定人与日期。
3. 写回 → 修改受影响的契约文件并把 `version` 加一；OPEN.md 中该行标为已裁定并链接到裁定文件。

**裁定权在团队，不在本仓库。** 本仓库只负责收集、记录和写回。已在 DATA-02 本体里裁定的事项，以本体为准，不重复裁定。
