# 诚实边界

PoL2 以诚实为核心原则之一，检验它的方法本身也必须诚实。本项目的每份结果卡、每批数据都带下面这些声明，后续由门禁 G09 检查。

## 关于门禁

- 门禁只封住已经被想到的捷径。通过全部门禁，只说明没有用这些已知方式作弊，**不说明治理层有效**。
- 门禁本身也可能有错。发现门禁误判时，提 issue 并附反例，不在本地悄悄绕过。

## 关于数据

- `data/pilot/` 的 20 条是助手生成、未经人工审定的试例，`eligible_for_ranking` 永远为 false。
- 参考标签只要还没有经过两名独立标注者审定，就一律称为"待审标签"，不称为金标准。
- 合成数据和模型模拟得出的结论，不推广到真实人群。

## 关于结果

- 未改善、低于底线、门禁不过，都照常提交。负面结果和正面结果同样有证据价值。
- 反复看过的公开测试成绩不称为盲测成绩。盲测只在独立评测者保管的保留集上进行。
- 每个数字写明数据版本、底线并列、失败请求数、硬件类别。不同硬件上的延迟不放在一起排名。
- 不在公开文件里写机器细节：本机路径、显卡型号、邮箱、账号名。硬件只写结果卡需要的类别，例如"单张消费级 GPU"。
