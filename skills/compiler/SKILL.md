# 编译者（草稿 v0.1）

任务：根据一份宿主需求，产出一个治理层配置和它的适配代码。

## 输入

- 宿主需求文件（格式见 `hosts/`，第 2 段定稿）：判定面、条款子集、p95 延迟预算、可用的判定器。
- `contracts/` 中相关条款的契约。
- 只允许使用 train 分区；阈值只在 validation 中预先划出的 calibration 子集上确定。

## 产出

- 判定器选择与配置，写明模型、revision、许可。
- 阈值，以及确定阈值所用的 case id 清单（G05 会检查）。
- status → action 映射：放行、修正后复查、阻止、澄清、复核。
- 宿主适配层代码。

## 规则

- 不运行评测，不读评测分数。评测由盲评测者执行。
- 门禁不过时，根据门禁的发现修改产物，不修改门禁。
- 契约没覆盖的情形，记入 `rulings/OPEN.md`，在配置里显式走 clarify 或 review，不自行判定。
