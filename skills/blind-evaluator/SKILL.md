# 盲评测者（草稿 v0.1）

任务：在看不到参考答案的条件下运行编译产物，生成预测文件，交给门禁计分。

## 输入

- 由 PoL-Governance `benchmark/export_inputs.py` 导出的无标签输入：只有 id 和 input。
- 编译产物（判定器配置、阈值、映射、适配层）。

## 步骤

1. 确认输入文件里没有 proposal、参考标签、场景族名或能暗示答案的文件名；有就停止并报告。
2. 逐条运行，记录 status、issues、action、latency_ms、execution_status。失败照实记录，不重试到成功为止。
3. 把预测文件和运行环境说明（硬件类别、并发、版本）交给 `gates/run_all.py`。
4. 结果卡如实填写门禁结论，包括 `fail` 与 `incomplete`。

## 规则

- 不接触私有保留集。保留集评测由独立评测者在库外进行。
- 不根据单条结果修改编译产物，也不把单条结果转告编译者。只报告汇总指标和门禁结论。
